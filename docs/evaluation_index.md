# 方案 E 评估数据总索引（2026-07-10 整理）

这份文档把两天实验产生的全部数据目录串成一张地图。写论文时，每一节的
素材都可以从这里直接定位到原始数据，不需要再翻目录考古。所有目录都在
`results/` 下，每个目录内有 `summary.md`（结论与方法）和逐 tick 的
JSONL 原始数据（接收端记录每周期的 r/e/s/vq，发送端记录 R/pace/mode）。

## 主线：里程碑验收（论文评估章节的骨架）

**m0_flowset_count_20260709 — 测量面有多准？**
逐流集合计数与硬件 vport 计数器交叉验证误差全部在 0.01% 以内，与
iperf3/ib_write_bw 自报速率对照误差 ≤0.11%（修正重传与头部开销后）。
读取路径 p50 只要 0.9ms。这个目录还记录了旧系统两个缺陷的取证过程
（详见 ops_notes.md），以及两条方法学教训：TCP 的期望值必须加上重传
字节；perftest -D 模式的 iterations 列不可靠，要用 BW×时长。

**m1_policy_tcp_20260709 与 m1b_policy_rdma_20260709 — 单类政策瓶颈闭环。**
完整控制环第一次跑通的记录。TCP 稳态均值偏差 −0.2%，RDMA 三段稳态
−2.6%/−2.1%/−1.1%、逐周期带内率 89-92%。下行政策阶跃 3-4 个周期首次
进带（验收线是 10），含下冲恢复的完全稳定 17-25 周期，冷启动约 45 周期
——这组数字支撑"收敛双指标"的叙述（Q25）。M1 的 summary 还记录了三个
实现期修正（VQ 排空死锁、V_max 收紧、app-limited 窗口）的前后对比。

**m2_class_borrow_20260709 — 类间权重与借用。**
权重 1:1 实测 1.03，切到 3:1 实测 2.80，借用时空闲类的份额被另一类
拿走 98%，回归后 2 个周期内让出。这是"政策可编程"的正面证据。目录里
另有 per-class A 的重测数据（m2r_ 前缀），显示利用率 +4pt 但比例漂移
——后来被 Q27 归入三条权衡之一。

**m3_incast_20260709 — 物理瓶颈上的公平。**
接收端线速降到 100G 制造 incast，四条流各分到理论份额的 −4.5%，相互
之间 spread 只有 0.05%——这是全部数据里最漂亮的公平性数字。churn 一节
（第 4 条流以满额度突发加入）给出乐观起步的物理代价：ping 个别样本
114ms，约 50 周期重新等分。headroom 的保护性对照两组 ping 完全相同，
原因（锯齿自带欠载，聚合顶不到线速）写进了 summary，是诚实的负结果。

**m4_robustness_20260709 — fail-open 与参数扫描。**
遥测断流后 0.3s 冻结（N1）、2.36s 进入斜坡回升（N2）、爬到发送端树
上限后钉住、接收端恢复后 1 秒内重新受控——与 §3.5 的时序逐字吻合。
8 组参数扫描是 Q27 终裁的第一批输入。

**m5_tree_baselines_20260709 — 发送端树、min 不变式、三方对比。**
发送端 5G 硬上限与接收端 6G 政策同时存在时，紧的一方（4.95G）生效。
B0（无隔离：TCP 37G/RDMA 147G，政策完全失效）、B1（静态半分：TCP 空闲
时 RDMA 只能拿 3G，一半份额浪费）、E（比例可编程 + 借用 98%）——论文
主对比图的三列数据都在这里。

## 支线：扩展实验与参数终裁

**m5c_oversub_20260710 — 超售语义。** 4 个 VM 各售 20G，压进 48.5G
容量：全速时四流 11.94/11.93/11.93/11.97（理论 12.1），一个 VM 自限
5G 后其余三流各 13.7G、无一超过售出额度。售卖原则（Q23）的直接验证。

**m5d_devlink_soak_20260710 — 硬件第一层。** devlink 限速带载操作 14 次
无一异常（推翻了旧的"永不碰"结论），以及硬件 8G 上限与 E 层超售分配
叠加的组合实验（vf0 被硬件钉住 7.72G，E 自动把释放的份额分给其余三流，
误差 1%）。两层模型（Q23）的落地证据。

**f1f2_20260710 — 利用率探索的完整战役。** 这个目录浓缩了 Q26/Q27 背后
的全部实验：F2 三段恢复的采纳数据、F1 峰值滞回和 F3 大余量的否决数据、
份额保底把账面缺口清零但利用率反降的关键实验、以及干净 RP 上全局 A 的
终裁对比（0.1G 比例 1.01 对 0.25G 比例 21:1）。三条结构性权衡
（§5.4）的每一条都能在这里找到正反两组数据。

**a_rescan_20260710 — 全局 A 初扫。** 五档 A 值下利用率对 A 不敏感的
首次证据，引出了"驻留欠账"的诊断（后被 grant 塌陷诊断取代，过程见
docs/archive/tuning-and-diagnostics-log.md）。

**scale_overhead_20260710 — 控制面开销与规模。** 2/8/20 个流集合下的
分段计时：优化前调度段 1.9ms、优化后 448µs（单遍 ceiling 算法，等价性
经 12600 个随机用例验证），两端 agent 的 CPU 都在单核 9% 以内。舒适
上限从约 50 个流集合推到数百。论文 overhead 小节的全部素材。

**soak_20260710 — 长稳记录（持续积累中）。** cron 每 15 分钟一轮流量、
每 5 分钟一次体检的观测日志。用于回答"新栈能不能连续跑一周"。
