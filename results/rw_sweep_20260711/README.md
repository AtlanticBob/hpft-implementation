## 晚间续：TCP@6G、M2 与两个新修复

TCP@6G 全环（goodput/30s）：50ms 4.87/4.95G；1ms 5.35/5.32G。
M2 协议：RDMA -D 75 全程 + iperf3 在 [15,45]；每轮新鲜 RP。
- 1ms 修复前：RDMA 被饿死到 0（RP 死锁，bud=12.6G lvl=0.02G）
- 1ms 修复后（MD 下界 0.3r + RP 喂率抖动）：借用 3s 回 5.98G、回收 1s、
  竞争期客户端真值 rdma≈1.4/tcp≈3.5（比例 0.40）、秒级振荡 stdev≈1.9/1.6
- 50ms 同协议对照：真值比例 0.25、借用恢复仅 5.42G、振荡相当 → 1ms 不劣化
- rx 侧归因比例读数（1.06-1.15）是 megaflow 构成比 2s 滞后造成的假象
回归：修复后 1ms M1b 5.66G 持平，50ms M1b 5.29G 略升。
