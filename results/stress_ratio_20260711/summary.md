# 压测 D2：类权重极端比例（2026-07-11）

单对 vf0、dst MaxRate 6G、两类全速竞争 90s，扫 rdma:tcp 权重
1:1 / 3:1 / 4:1 / 8:1 / 1:4，每点 3 rep、rep 间 RP+tx agent 全新。
runner=ratio_run.sh，分析=analyze_ratio.py，原始数据 ratio_rx.jsonl。

## 结论一：比例跟随到 8:1 全部守住 ±10%，假设"8:1 破线"证伪

竞争段 wire 口径比例（每点 3 rep）：

| 目标 | 实测比例 | 误差 |
|---|---|---|
| 1:1 | 1.02 / (0.57*) / 1.02 | +2% |
| 3:1 | 3.10-3.13 | +3.4~4.2%（历史锚 3.24 为 +8%，更好） |
| 4:1 | 4.11-4.19 | +2.7~4.8% |
| 8:1 | 8.40-8.54 | +5.0~6.7% |
| 1:4 | 0.25-0.26 | +1.0~5.8% |

偏差随比例温和放大（强类恒略多拿），无突变悬崖；弱类 0.6G 档
未见死锁。*1:1 rep2 是发作性异常，见结论二，不计入比例统计。

## 结论二：发作性 RDMA 崩塌——完整病理链（本轮最重要发现）

rep2（15 个 run 中 1 个）出现周期性 RDMA 崩塌（3s→8s→20s 逐次加
重，均值 1.96G/应 3G，最低 0.14G）。240s 定向复现（repro_run.sh，
1Hz 0xdeb 内窥）成功，四段病理链全部取证：

1. **触发（设计层）**：执行器全额兑现 pace=ceil×1.05=3.15G 时，
   r 持续高于 grant e=3.0 约 5%，VQ 以 0.15G 速率净充入，约 10s
   饱和 → 标记风暴 → MD 把 R 压到 ~1G。probe_over_grant=1.05 的
   安全性**隐式依赖执行器兑现率 <100%**（M2 时代 wire/budget≈0.95
   把这层耦合藏住了；兑现率逐 run 波动，因此发作是间歇的）。
2. **level 滞后（已缓解）**：R 快速下降期每步预算变化 >3% 穿过滞
   回 → settle-hold 连续重臂 → 积分冻结 → level 比例跟降。预算一
   稳（滞回生效），积分 1-2s 内把 level 拉满——D1 的活锁修复有效，
   0xdeb 实证 bud=lvl=3.15。
3. **RC 传输停摆（数据通路层，未解决）**：深度 pace 窗口后 QP 进
   入 RC 病理：满预算、满 CC 下 wire 只有 0.1-0.9G，且 dbg_epochs
   冻结 ~7s（CC 事件流完全停止=QP 停摆）。与历史 vf1 bug 同族
   （65KB 消息 + 深 pace → RC 重传窗口病理）。
4. **突然自愈**：t=214 满血恢复 3.12-3.15G 稳到结束。

D1 batch B 里 vf0/vf3（4 路扇出源）的 −20%/高 sdev 特征与此同根。

## 处置

- 阶段 1 属设计问题，记录待用户裁决。候选：probe_over 降到 ~1.02；
  或 VQ 充入对 wire/grant 偏差留容差；或执行器目标兑现率钉在 ~0.97
  （device 码，禁区）。
- 阶段 3 属数据通路鲁棒性（RC 重传窗口 vs 深 pace），与 EDT 乱序税
  同列独立工作线；min-level 地板（bud/128）挡不住这一族。

## 复刻扫描（sweep 2，同协议 + 执行器逃逸绊线，13:45-14:12）

第一次扫描的原始数据在 sweep1/，第二次在顶层（runs.tsv 等同名文件）。

15 rep 中 13 个复刻第一轮：比例误差 +1.9%~+8.8%，随比例温和放大，
全部 ±10% 内，8:1 仍不破线。发作性 RDMA 崩塌出现 2 次——3:1 rep3
（比例塌到 1.28，sd_r 1.98）和 1:4 rep3（弱类 RDMA min 0.14G）。
两轮合计发生率 **3/30**，全部在 RDMA 侧，强类（3:1）弱类（1:4）
两个方向都会中招，与病理链的"执行器兑现率波动决定是否触发"一致。

**绊线验证通过**：13 个健康 rep 零误报；3:1 rep3 的超发相被精确捕获
（r=4.5-4.8G vs pace=1.4G，比值 3.3×=RC 重传风暴签名，告警窗口与
崩塌 rep 完全重合）。1:4 rep3 的停摆相无告警——符合设计（绊线只测
r>1.5×pace 的逃逸；停摆相 r≪pace 在控制面视角与 app-limited 不可
分，需 QP 级 dbg_epochs 才能判别）——**停摆侧的观测性缺口**记为
遗留。

实验后 lab 已交回稳定态：registry 20G/1:1 三副本一致（md5 核对）、
RP+tx agent 新鲜、soak cron 恢复、单流 sanity 18.33G@20G。
