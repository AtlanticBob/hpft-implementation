# 压测 D7：参数边界扫描（2026-07-12）

两个负载：W1 单对两类竞争（vf0/6G/1:1，60s/点，27 点，逐点全新
rx+RP+tx 以确保 rx 侧 V/rate_window 生效）；W2 root 短缺区（4 直连对

## W1 结论：默认点坐落平坦区中央，只有两个失稳悬崖，都在"太慢/太粗"方向

| 参数 | 扫描范围 | 悬崖 | 备注 |
|---|---|---|---|
| a_frac_linerate | 0.0001–0.0025 | **0.001 崩**（比例 0.50、发作、OSC）| 默认 0.0005 安全；复现历史"大 A 赢家通吃" |
| rate_window_s | 0.006–0.1 | **0.1 崩**（比例 0.74、发作）| 测量窗跟不上秒级竞争；默认 0.02 稳 |
| beta | 0.1–0.7 | 无 | 全程比例 1.03-1.04；β=0.1 略抖（sd 0.24）|
| v_periods | 0.5–8 | 无 | 单对下 V 不敏感 |
| probe_over_grant | 1.0–1.3 | 无 | **1.0（零余量）也 ok**（比例 1.01）——印证 probe_cap 衰减设计：余量存废对单对稳态几无影响 |
| probe_gain | 0–100 | 无 | 修复引入参数全程宽容 |
| rdma_bud_slew_per_s | 0.1–1.0 | 无 | slew 强度不敏感 |

强正面结论：本轮修复引入的三个新参数（probe_gain / probe_over /
slew）在单对场景**没有一个有悬崖**，默认值不是脆弱魔法数。a_frac 的
0.001 悬崖有意思——它比默认只大 1 倍就崩，说明 A 是全系统最敏感的
旋钮，1ms 下尤其（复利放大），值得进论文敏感性图。

## W2 结论（重磅）：D4 的 root 同步振荡是参数问题，不是机制问题——V 加倍即根治

默认（V=2）在 W2 精确复现 D4 病态：agg 46.3G（48%）、sd 9.97、
四流相关 0.99（完全同相）。**V_periods 2→4 一步解决**：

| 点 | 聚合 | 每流 sd | 同步度 | 结论 |
|---|---|---|---|---|
| V=2（默认，=D4） | 46.3G | 9.97 | 0.99 | 病态 |
| **V=4** | **95.3G (98%)** | **0.04** | 0.79 | 四流 23.84G，spread **0.0%** |
| V=8 | 95.2G | 0.06 | 0.88 | 同样满血 |
| V=16 | 95.3G | 0.04 | 0.84 | 同样满血 |
| A=0.00025（半） | 94.9G | 0.04 | 0.79 | 也满血 |
| beta=0.15 | 95.3G | 0.06 | 0.50 | 也满血 |

机理：root 区同步振荡源于所有流被一起标记、一起深砍。V（标记满刻度，
容忍的超额积分比特量）加倍让虚拟队列更晚饱和，把"同步硬砍"软化成
"温和涟漪"，AIMD 锯齿的幅度塌到近零。**V=4 不仅治好 root 区，还反超
历史 M3@50ms 基线**（旧律 21.9G/流 90%，V=4@1ms 23.84G/流 98%），
且 W1 证明 V=4 在单对场景无副作用（sd 0.03、util 5.87）。

## 待用户裁决：V_periods 默认 2→4

这是一个参数默认值变更（非机制变更），但影响 root 区的核心承诺，按
规矩报给用户定。证据：V=4 在两个负载都不劣于 V=2、在 root 区从 48%
跳到 98% 且完美公平。风险：V 是固定比特量（不随周期缩放），加倍意味
虚拟队列对持续超额的响应慢一倍——W1 的 V=8 单对点已证明慢一倍无害，
但更激进参数或更高流数下的锯齿幅度需在采纳前补一轮确认。lab 现仍为
V=2 默认稳定态。
